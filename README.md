# Coinsy – download

Qui trovi l'ultima versione di **Coinsy**, l'app per gestire stipendio, spese e scadenze.

**Scarica:** [Coinsy.apk](https://github.com/dario7rugby36-svg/coinsy-download/raw/main/Coinsy.apk)

1. Apri il file dal telefono e tocca *Installa* (se Android lo chiede, consenti "Installa app sconosciute").
2. Se avevi già Coinsy, si aggiorna e i tuoi dati restano.

L'app controlla da sola, a ogni apertura, se qui c'è una versione più nuova (`version.json`) e propone di scaricarla.
I dati restano solo sul telefono: questo repository contiene solo il file da scaricare.
